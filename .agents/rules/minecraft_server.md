# Правила проекта Minecraft Server

Этот проект — публичный сервер Minecraft, разрабатываемый совместно двумя разработчиками через Antigravity 2.0.

## Стандарты разработки:
1. **Ядро сервера:** Paper / Purpur (версия 1.21+).
2. **Конфигурации:** Все изменения плагинов делать аккуратно, комментируя нестандартные настройки в YAML файлах.
3. **Безопасность:** Никогда не коммитить секретные ключи, пароли БД (MySQL/PostgreSQL) и RCON-пароли в открытом виде.
4. **Синхронизация:** При добавлении новых плагинов или изменении механик обновлять файл `SERVER_ROADMAP.md`, чтобы второй разработчик и его агент знали текущий статус.
5. **Тяжелые файлы:** Миры (`world/`), логи и кэши игнорируются в Git. Синхронизируются только конфиги, скрипты и кастомные плагины.
