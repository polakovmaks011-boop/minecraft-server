# План разработки и статус сервера

## 1. Базовая настройка
- [ ] Установить Java 21 на хост-машину
- [ ] Загрузить ядро сервера (Paper/Purpur)
- [ ] Настроить стартовый скрипт (`run.bat` / `run.sh`)
- [ ] Принять EULA (`eula=true`)
- [ ] Оптимизировать `server.properties`, `paper-global.yml`, `purpur.yml`

## 2. Базовые плагины
- [ ] **LuckPerms** — система прав, групп (Owner, Admin, Mod, Default/Player)
- [ ] **EssentialsX** (или аналоги: CMI/SunLight) — спавн, варпы, базовые команды
- [ ] **WorldGuard + WorldEdit** — защита регионов и спавна
- [ ] **Vault** + экономический плагин
- [ ] **AuthMe Reloaded** (или связка с онлайн-режимом / скинами)
- [ ] **TAB / DecentHolograms** — визуальное оформление

## 3. Геймплей и защита
- [ ] Кастомный спавн
- [ ] Античит (GrimAC / Vulcan)
- [ ] Защита от крашей и эксплойтов

## 4. Запуск и публикация
- [ ] Перенос на VPS
- [ ] Подключение домена (например, `play.myserver.com`)
- [ ] Настройка резервного копирования (авто-бэкапы)
